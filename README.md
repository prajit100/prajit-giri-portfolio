# Prajit Giri Portfolio

Professional portfolio for Prajit Giri, an EY finance and compliance professional working across partnership tax, financial analysis, analytics, and public service.

## Highlights

- Responsive, accessible portfolio design
- Professional experience and selected analytics projects
- Education, certifications, and downloadable resume
- Built with Next.js, React, TypeScript, and Vinext

## Development

Install dependencies and run the local development server:

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```
